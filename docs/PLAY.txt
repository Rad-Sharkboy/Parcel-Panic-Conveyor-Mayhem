Parcel Panic: Conveyor Mayhem - V2

Windows 11, 64-bit | 1360 x 765 window
Extract the whole ZIP, then open ParcelPanic.exe.
Keep the assets folder beside the EXE. No compiler is needed to play.

Left click: switch a cyan junction
Right click: brake a belt temporarily
Hover over a parcel: show its information
Space/Esc: pause/resume
Z while paused: undo a junction switch
H: Help/Factory info
Q: view another input queue on the sidebar
F1/F2/F3: practice examples for the queue/heap/hash table
Enter in a sample: next operation; Backspace: restart; Esc: close
F4/Shift+F4: next/previous level
F5: restart
I: inspect the current run's queue, heap, hash table and undo stack (Press I again to return to paused planning)
Inspector: Tab changes view, Enter advances one real tick, arrows change pages
Hash tab: type ID, Backspace edits, L looks it up
Stack tab: J selects a junction, S switches/pushes, Z undoes/pops
Each shift starts paused with a briefing; Enter or its button starts play.
Hover a junction for route previews. The loading bay highlights the next shipment.

Match R/B/Y parcels to their docks. X goes to recycling.
"F" means fragile; "!" means express. Reach both the quota and score target to advance.

V2 adds live inspection, clearer input staging, shared loading-bay information, route previews and skippable shift briefings.
Source and updates: https://github.com/Rad-Sharkboy/Parcel-Panic-Conveyor-Mayhem
